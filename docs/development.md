公开内容按最终实验用途选择，包括模型输入、最终 Simulink 模型、结果图表、MATLAB 使用入口和学术引用。代码与模型使用 MIT，数据、图表和文档使用 CC BY 4.0。具体范围见 [许可说明](../NOTICE.md)。

## 已完成的检查

- 核对 9 组电流与电压时间轴：均从 0 s 开始、间隔 1 s，共 405,207 条配对记录，无 NaN 或 Inf。
- 核对 MAT 数组与 CSV 导出值逐项一致，以及三组 OCV–SOC 数值。
- 对照论文和最终指标表，核对 27 组 MAE/MSE 报告值；已知数值一致性事项见 [实验结果](results.md)。
- 检查三个模型中引用的数据文件、实验入口使用的块路径及参数配置。
- 清理公开文件中的本机路径、编辑者和编辑历史元数据，以及模型中的调试手记；保留实验数组、模型算法和参数。
- 检查 README、文档、数据索引、图像与相对链接，并提供 [SHA-256 清单](../checksums.sha256)。

## 验证限制

本次发布环境未安装 MATLAB/Simulink。新增 MATLAB 入口经过静态检查，**未执行 MATLAB 仿真**；因此没有声明编译通过、运行通过或逐项复现论文表格。`validate_release.m` 也需在使用者的 MATLAB 环境中运行。

目前没有按每组工况逐行确认的论文评价区间文件。`run_experiment` 不猜测这些区间，默认仅输出时间序列，明确提供 `MetricWindow` 后才计算指标。

## 维护约定

新仿真和缓存写入 `build/`，该目录由 Git 忽略。新结果应附上输入版本、工况、电池参数、方法、时间范围和 MATLAB 版本，经过核对后再收录为公开结果。不要直接覆盖论文报告表。

修改数据、模型或文档后，请更新版本、更新日志和 SHA-256 清单。新增文件应按许可范围保持相应署名信息。
