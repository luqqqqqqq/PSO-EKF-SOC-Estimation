## 指标定义

MAE 为绝对 SOC 误差的均值，单位为百分点。MSE 为 SOC 误差平方的均值，单位为百分点评方。G1、G0、PSO 分别对应 G=1、G=0 和 G=G_PSO。

## 平均相对改进

论文报告 PSO 相对 G1 的平均 MAE 降幅为 27.64%，平均 MSE 降幅为 39.24%。这里的平均是九个电池/工况组合各自相对降幅的算术平均，不是将所有采样点合并计算。个别工况的降幅为负，不能解读为每组工况都优于 G1。

按表中四位小数计算，MAE 平均相对降幅为 27.6436%，MSE 为 39.2461%。后者与论文写出的 39.24% 存在末位差异；仓库分别保留论文报告值和由公开表计算的值。逐组结果见 [relative_improvement.csv](../results/tables/relative_improvement.csv)。

## 已知数值一致性事项

如果 MAE 和 MSE 使用相同单位、相同误差样本以及相同权重，应满足 MSE ≥ MAE²。原表以下两项不满足这一关系，且差异大于四位小数的舍入误差：

| 电池 / 工况 / 方法 | 报告 MAE | 报告 MSE | MAE² |
| --- | ---: | ---: | ---: |
| A / NEDC / PSO | 0.2039 | 0.0305 | 0.04157521 |
| C / NEDC / PSO | 1.1937 | 1.2465 | 1.42491969 |

本版本如实保留已发表数值，不推测或替换可能的正确值，也不将其标记为已重新验证。使用这两行进行定量比较时，应另行核对原始误差序列与评价区间。
