# 论文引用

[返回项目首页](../README.md) · [文档导航](README.md)

研究方法与论文结果请引用正式发表的论文。使用本仓库的代码、模型或数据时，还应记录仓库版本或提交，便于其他研究者定位相同的实验材料。

## 正式论文

**Accurate state-of-charge estimation of LiFePO4 battery: An adaptive extended kalman filter approach using particle swarm optimization**

Xihong Lu, Mingyang Chen, Yong Tian. *Energy Reports*, **14** (2025), 1169–1178.

- DOI：[10.1016/j.egyr.2025.07.023](https://doi.org/10.1016/j.egyr.2025.07.023)
- 出版社原文：[ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2352484725004500)
- 下载论文引用：[BibTeX](../CITATION.bib) · [RIS](../CITATION.ris)

以上引用以出版社登记的作者顺序、题名、期刊、卷、页码和 DOI 为准。RIS 可导入 Zotero、EndNote 等文献管理工具。论文全文及其适用许可请通过出版社页面获取。

## 仓库版本引用

论文 DOI 标识论文，不是软件或数据仓库的独立 DOI。本仓库目前没有单独登记 DOI。

引用首个实验版本时可使用：

> PSO-EKF-SOC-Estimation contributors. (2026). *PSO-EKF SOC Estimation* (Version 1.0.0) [Code, models and data]. GitHub. https://github.com/luqqqqqqq/PSO-EKF-SOC-Estimation/tree/v1.0.0

- 实验版本：[v1.0.0](https://github.com/luqqqqqqq/PSO-EKF-SOC-Estimation/tree/v1.0.0)
- 对应提交：[1b6fb39](https://github.com/luqqqqqqq/PSO-EKF-SOC-Estimation/commit/1b6fb39ab953f6a3d4cb690368c90dbf2aee4d66)
- 下载仓库引用：[repository.bib](repository.bib)，采用兼容传统 BibTeX 的 `@misc` 条目。

若使用后续修改，请将引用中的版本或提交替换为实际使用的版本。仓库贡献者署名与论文作者署名分别记录，不据论文共同署名推断软件贡献。

## GitHub 引用入口

顶层 [CITATION.cff](../CITATION.cff) 使用 Citation File Format 1.2。其 `preferred-citation` 指向上述论文，因此 GitHub 的 **Cite this repository** 入口默认生成论文引用。需要引用具体实验材料时，再附上仓库版本引用。

代码、数据和文档的许可按 [NOTICE.md](../NOTICE.md) 中的范围分别适用；引用论文不代替保留许可证与必要署名。
