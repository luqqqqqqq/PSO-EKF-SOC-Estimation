## 已发表结果与模型重跑

`results/tables/paper_metrics.csv` 是论文 Table 2 的报告值。结果图与数值输入对应最终实验资料。`scripts/` 提供的入口用于重新运行发布模型，重跑输出写入 `build/`，不覆盖已发表结果。

当前公开资料没有给出能逐行确认的完整论文统计区间配置，入口因此要求显式指定 `MetricWindow` 后才计算指标。本次发布环境也没有 MATLAB/Simulink，不能声明新增入口已经数值复现 Table 2。

## 模型职责

| 模型 | 用途 |
| --- | --- |
| `PSOmodel.slx` | 保存三组电池的 RC、OCV、容量、噪声与平台期增益配置；公共实验入口使用此模型 |
| `EKFmodel.slx` | 基础 EKF 和平台期增益验证 |
| `RCmodel.slx` | 二阶 RC 等效电路端电压验证 |

三个模型各自保存完整配置。不同模型的参数组不能相互替换来推断同一次实验的设置。公共入口从 `PSOmodel` 中选择对应电池的已存参数，保留算法和数值，不重新辨识模型参数。

## 单组实验接口

```matlab
result = run_experiment(battery, cycle, method, Name, Value);
```

| 参数 | 可选值或含义 |
| --- | --- |
| `battery` | `'A'`、`'B'`、`'C'` |
| `cycle` | `'HPPC'`、`'FUDS'`、`'NEDC'` |
| `method` | `'G1'`、`'G0'`、`'PSO'`、`'FIXED'` |
| `StopTime` | 默认最后一个测量时刻；不能超出数据范围 |
| `MetricWindow` | `[起始秒 终止秒]`，包含边界；省略时不计算汇总指标 |
| `FixedGain` | `FIXED` 方法的平台期常数增益 |
| `WriteResults` | 默认 `true`；设为 `false` 仅返回内存结果 |
| `OutputDir` | 默认 `build/results/`，每次使用独立子目录 |

`G1` 是标准 EKF。`G0` 仅在模型定义的平台期关闭更新。`FIXED` 同样遵守模型的 SOC 门控，不能解释为全程关闭或全程常数增益。`PSO` 使用模型中保存的离线增益曲线，运行时不重新搜索。

模型用库仑计数构造参考 SOC。时间序列中 `soc_reference_pct`、`soc_estimated_pct` 以百分数表示，`soc_error_pp` 为估计值减参考值，单位为百分点。参考 SOC 并非独立仪器直接测得的 SOC 真值。

发布模型的 PSO 增益区间由库仑计数的 `SOC_Ah` 信号选择。它是离线实验中的既有实现；入口保留这一信号来源，没有改为估计 SOC。直接部署到实际 BMS 前需要单独评估该设计。

`PSOmodel` 中的参考 SOC 初值为 1，估计 SOC 初值为 0.95，两个 RC 电压状态初值均为 0.5 V，初始协方差对角元素为 0.01。三组参数如下；这是发布模型内的配置，不是重新辨识值：

| 电池 | 库仑计数容量（A·s） | 测量噪声 R | 过程噪声对角元素 |
| --- | ---: | ---: | ---: |
| A | 98654.634216 | 0.2 | 9e-10 |
| B | 91814.5332 | 0.182 | 1e-9 |
| C | 97908.0261 | 0.7997 | 1e-8 |

模型还包含电流与电压噪声源。入口保留模型原有设置；不同 MATLAB 版本或噪声源配置可能影响数值结果，运行时应一起记录。

MAE = mean(abs(error))，MSE = mean(error.^2)，RMSE = sqrt(MSE)。指标 JSON 同时记录实际首末采样时刻、样本数、模型参数和 MATLAB 版本，便于比较相同条件下的运行结果。

## 批量实验

```matlab
allResults = run_all();
```

运行三电池 × 三工况 × 三种方法，共 27 次仿真。每次都使用完整测量时间范围，不自动计算论文统计指标。HPPC 数据较长，建议先完成单组实验。

## 离线 PSO 搜索

```matlab
search = optimize_gain('B', [27361 31321], 'Seed', 0, ...
    'Particles', 2, 'Iterations', 50);
```

这是新一轮单区间搜索的使用示例。目标函数为指定 HPPC 时间区间内的最大绝对 SOC 误差，搜索 G ∈ [0, 1]。惯性权重 0.6，个体和群体学习因子各 0.1，默认 2 个粒子、50 次迭代。初始速度范围为 [-0.005, 0.005]。随机种子可指定，调用结束恢复先前随机状态。

每次适应度评估都从时间 0 运行模型；给出的区间不是论文已确认的优化区间。该入口将最终方法整理为可读的搜索实现，不代表恢复原始随机试验，也不会修改模型中的最终增益曲线。把多个区间的结果重新拟合为曲线属于新的标定工作。

## 使用边界

实验数据对应 25 °C 下的这三组电池。更换电芯、温度、老化状态或传感器配置后，应重新验证模型与增益。模型重跑、参数再标定和论文报告值是不同结果来源，请在研究中注明实际使用的设置。
